# Микрокосм 16.1

Откройте **microcosm_16_1_pc.html**. Интернет не нужен. Требуется современный браузер с WebGL2.

«Гулять по миру» разворачивает карту и включает вид от первого лица. WASD / стрелки — идти; Shift — быстрее; пробел — прыгнуть; мышь — обзор; Esc — вернуться. При недоступности захвата указателя используйте перетаскивание. На сенсорном экране есть кнопки движения и прыжка.

На карте: колесо — масштаб; перетаскивание — перемещение; правая кнопка — поворот и наклон. «Облака и осадки» включает погодные эффекты. Они следуют погоде текущего места и времени. В режиме «Экономно» трава менее плотная.

Под картой раскрывается справочник **«Биомы мира · 19 типов местности»** с фактическими количествами клеток. Горы представлены скалами, горной тундрой и высокогорными лугами. Все 19 типов поддерживаются, но не каждый обязательно присутствует в одном сохранении.

Изменения и результаты проверок описаны в microcosm_16_1_RELEASE_NOTES.md. Примеры отрисовки находятся в previews. Исходная версия 15.0 включена для воспроизводимой сборки; открывать следует версию 16.1.

Для размещения сайта переименуйте microcosm_16_1_pc.html в index.html и загрузите на хостинг. У каждого посетителя будет отдельная симуляция.

Для разработки: python src/build.py; node tests/scene.cjs; python tests/render_egl.py; node tests/simulation.cjs. Для воспроизведения графики нужны EGL/OpenGL ES и Pillow. Браузерные fullscreen/pointer lock необходимо дополнительно проверить на устройстве.
