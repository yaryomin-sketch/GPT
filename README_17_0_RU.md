# Микрокосм 17.0

Откройте **microcosm_17_0_pc.html** в современном Chrome, Edge или Firefox с WebGL2. Файл автономный: модели, материалы и сохранённый мир встроены. Интернет для игры не нужен.

## Управление

- «Гулять по миру» — вид от первого лица и разворот карты.
- WASD / стрелки — идти, Shift — быстрее, пробел — прыгнуть, мышь — обзор.
- Esc — вернуться к карте. Если захват мыши недоступен, используйте перетаскивание.
- На карте: колесо — масштаб, правая кнопка — поворот и наклон, «Весь мир» — общий вид.
- «Погода» включает облака и осадки. Ясная погода не создаёт искусственные облака или дождь.

Под картой есть справочник 19 типов местности с количеством клеток в текущем мире. Мелкие животные физически невелики: приблизьте карту или найдите вид через поиск. На обзорной карте масштаб существ увеличивается автоматически; при прогулке используется обычный масштаб.

Изменения описаны в microcosm_17_0_RELEASE_NOTES.md. В previews — отрисованные проверочные кадры, включая отдельные виды гор, реки, травы, облаков и моделей. Изображение biomes показывает специально подготовленный тест всех материалов, а остальные ландшафты используют исходный мир.

## Сборка

Из корня пакета: `python src/build.py`.

Проверки: `node tests/scene.cjs`, `node tests/water-edges.cjs`, `python tests/render_egl.py`, `node tests/simulation.cjs`. Для отрисовки нужны EGL/OpenGL ES и Pillow. Большой каталог tests/gl-data создаётся проверкой и не включён в архив.

Исходная версия 15.0 включена для сборщика; для игры открывайте версию 17.0. Модели и материалы стилизованные. Полноэкранный режим, захват мыши и FPS следует проверить в браузере на вашем устройстве.

Для хостинга используйте готовый HTML как index.html. Каждый посетитель получает независимую локальную симуляцию.
