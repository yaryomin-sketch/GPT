## Управление

- «Гулять по миру» — вид от первого лица и разворот карты на весь экран.
- WASD / стрелки — ходьба; Shift — быстрее; пробел — прыжок.
- Мышь — обзор; Esc — возврат к карте.
- Если браузер не разрешает захват мыши, используйте перетаскивание. Для сенсорного экрана есть кнопки.
- Колесо — масштаб карты, правая кнопка — поворот и наклон.

## Версия 16.1

Исправления исчезающих участков, очистки кэша, камеры и воды; плотная трава, объёмные облака, дождь и снег, усиленный горный рельеф. 13 стилизованных моделей существ. Клетка 40 × 40 м. Под картой — справочник 19 типов местности с количеством клеток текущего мира.

Подробности: [изменения 16.1](microcosm_16_1_RELEASE_NOTES.md), [инструкция](README_16_1_RU.md).

## Файлы и сборка

- `index.html` — готовая игра для обычного статического хостинга.
- `microcosm_16_1_pc.html` — тот же автономный HTML с номером версии.
- `releases/` — готовый архив версии.
- `src/` — рендерер, стили и сборщик.
- `tests/` — проверки и результаты.
- `microcosm_15_0_pc.html` — исходная версия, используемая сборщиком.

Сборка: `python src/build.py`.
Проверки: `node tests/simulation.cjs`, `node tests/scene.cjs`, затем `python tests/render_egl.py` (для последнего нужны EGL/OpenGL ES и Pillow).

Проверены 329 случаев видимости поверхности, работа кэша, прыжок, наличие травы при приближении, все модели и шейдеры в ES3-контексте. Полный браузерный прогон, системные разрешения fullscreen/pointer lock и FPS на устройстве пользователя ещё требуют проверки.

Каждый посетитель получает независимую локальную симуляцию. Общий многопользовательский сервер в эту версию не входит.
