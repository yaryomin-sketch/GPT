# Microcosm 18.1 — Babylon.js

Версия 18.1 заменяет только графическое представление версии 17.0 и подключает предоставленную пользователем музыку. Worker симуляции, общие правила мира и встроенное состояние сохранены побайтно. Масштаб клетки остаётся 40 м.

Распакуйте **всю папку** и откройте `index.html`. Интернет для игры не нужен. Можно разместить папку на обычном HTTP-сервере. Для существующего сервера Microcosm используйте корневой `index.html` репозитория вместе с папкой `babylon/`; серверная логика остаётся прежней.

Кнопка «Музыка» включает три композиции Jeremy Soule в порядке: Before the Storm → The Streets of Whiterun → Sky Above, Voice Within → снова первый трек. По умолчанию музыка выключена. Рядом доступны выбор композиции и общая громкость. Звуки мира включаются отдельно. При скрытии вкладки воспроизведение приостанавливается.

3D: Babylon.js 9.32.0, PBR-материалы с картами нормалей, готовые деревья и камни Kenney, анимированные Deer/Stag/Fox/Wolf от Quaternius. Остальные виды используют отдельные модели своей формы из 17.0; полная замена всех 19 видов библиотечными моделями ещё не выполнена. Текстуры земли, камней, травяного покрытия и снега — Poly Haven. Трава рисуется пучками из изогнутых лезвий с ветром; количество ограничено настройкой качества. Облака объёмные, с учётом глубины сцены; небо — материал внутри 3D-сцены. Реки используют непрерывную поверхность и анимированную карту нормалей воды.

«Гулять по миру»: WASD/стрелки, мышь для обзора, Shift для ускорения, Пробел для прыжка, Esc для выхода. Карта открывается на весь экран, при отказе браузера используется развёрнутый режим внутри страницы. Перемещается наблюдатель; состояние симуляции не меняется.

## Исправления 18.1

Исправлены исчезающие и чёрные поверхности земли: порядок вершин и стороны полигонов приведены к правой системе координат Babylon.js. Исправлена ориентация поверхности воды и берегов. Группы травы, деревьев и существ больше не перезаписывают буферы друг друга. Скорректированы освещение и цвета листвы. Убрана отдельная формула перетаскивания при больших наклонах; перемещение карты использует проекцию камеры и сохраняет высоту точки обзора во время жеста. Добавлены штатные beginFrame/endFrame движка для корректных таймеров анимации и счётчиков. В диагностике теперь есть сведения о готовности текстур, кадрах и ошибках шейдеров.

## Проверки

`python tests/setup.py`, `python src/build.py`, `node tests/music.cjs`, `node tests/camera.cjs`, `node tests/scene.cjs`, `python tests/shaders.py`.

Камера проверяется на 216 сочетаниях масштаба, наклона и поворота: перетаскивание должно следовать указателю с отклонением менее пикселя. Тест сцены проверяет загрузку GLB/glTF и анимаций, 19 разных моделей, ходьбу, прыжок, стороны полигонов, изоляцию буферов и неизменность замороженного снимка. Worker, общие правила и встроенный мир сравниваются с 17.0 побайтно.

`tests/gpu/render.cjs` отдельно выполняет настоящую отрисовку Babylon WebGL2 в Mesa EGL через нативные GLES-привязки; браузер для этого теста не используется. Проверены готовность всех текстур и окружения, отсутствие ошибок шейдеров, покрытие земли в 145 проекциях, густая трава и объёмные облака. Кадры находятся в `previews/`, отчёт — в `tests/gpu-verification.json`. Это не замер производительности вашей видеокарты. Проверка непосредственно в пользовательском браузере в этой среде недоступна.

Для GPU-теста на Linux нужны `libEGL.so.1`, `libGL.so.1`, Node.js и зависимости: `npm install --prefix tests/gpu`, затем `node tests/gpu/render.cjs`. Остальные Node-тесты используют локальный alias Babylon, создаваемый `tests/setup.py`; загрузка движка из интернета не нужна. Игре Node.js и Python не требуются.

Компиляция 48 этапов GLSL и связывание 24 программ также проверяются отдельно. В `src/engine-compat.js` сохранено исправление несбалансированной скобки в условии PREPASS закреплённой UMD-сборки 9.32.0. Трава использует MaterialPluginBase.
